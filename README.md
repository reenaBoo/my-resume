Меня зовут Карина, я фронтенд-разработчик с 5+ годами коммерческого опыта и большим вниманием к деталям.
Этот сайт является моим личным портфолио.

## 🚀 Установка и запуск

1. Клонируйте репозиторий:
```bash
  git clone https://github.com/reenaBoo/my-resume.git
```

2. Перейдите в папку проекта:
```bash
  cd portfolio
```

3. Откройте `index.html` в браузере или используйте Live Server

## 🛠️ Технологии

- **HTML5** - семантическая разметка
- **CSS3** - кастомные свойства, Grid, Flexbox, анимации
- **JavaScript (ES6+)** - современный синтаксис
- **Swiper.js** - слайдер проектов
- **Anime.js** - анимация текста
- **ScrollReveal.js** - анимация при скролле
- **RemixIcon** - иконки
